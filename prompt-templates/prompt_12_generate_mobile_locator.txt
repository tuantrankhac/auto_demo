Generate locator cho màn hình hiện tại của Android đang kết nối.

Yêu cầu:
- Đọc practices/mobile/android.md trước (device, appPackage, appActivity, appiumUrl).
- Làm đúng theo hướng dẫn trong android.md (ưu tiên Appium MCP; ADB là fallback).
- Kiểm tra thiết bị qua adb (adb devices).
- Mở đúng app theo practice (không generate khi đang ở Home Launcher / sai app).
- Lấy UI hierarchy (appium_page_source hoặc uiautomator dump).
- Đọc XML, phân tích element tương tác được.
- Sinh locator theo Coding Convention (Appium).
- Ưu tiên: accessibilityId → resource-id → content-desc → UiSelector → xpath.
- Kiểm tra PageUI mobile đã tồn tại hoặc tên tương đồng — giống thì mở rộng, khác thì tạo mới.
- Tạo / cập nhật class trong demo.mobile.pageUIs.
- Dọn file tạm sau khi xong.
